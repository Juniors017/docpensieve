Kinds this site added

Six kinds ship with the tool; these two are declared in the configuration of this very site, with a mark taken from an icon set:

Copilot

A passage drafted with an assistant, then read and corrected by a person. The reader is told which is which.

Claude

The same, and the page keeps its author: the byline above names a person, not a tool.

// docpensieve.config.mjs
admonitions: {
  claude: { label: 'Claude', tone: 'info', icon: 'simple-icons:claude' },
},

The mark is placed in the page when the site is built, like every other icon here: your reader downloads nothing, and no request leaves their browser.
