# À votre main

Deux modules plus loin, le site fonctionne. Il ressemble aussi exactement à
celui de tout le monde.

Ce module y remédie en trois passes : les couleurs qu'il porte, la façon dont
un lecteur s'y déplace, et les blocs qui arrêtent un lecteur sur le point de se
tromper.

## En un coup d'œil

<Columns>
  <Column>
    <Skill name="Difficulté" level={55} showValue={false}>
      Intermédiaire — vous avez généré un site et écrit quelques pages.
    </Skill>
  </Column>
  <Column>
    <Skill name="Durée" level={60} showValue={false}>
      Environ une heure, répartie sur trois leçons.
    </Skill>
  </Column>
</Columns>

<Admonition type="tip" title="Rien ici n'est obligatoire">
  Un site sans rien de tout cela reste un très bon site. Chaque leçon est un réglage ou un composant
  — prenez ceux dont vos lecteurs ont besoin, laissez le reste.
</Admonition>

## Ce que vous aurez changé

| Leçon      | Ce qu'elle touche                                              |
| ---------- | -------------------------------------------------------------- |
| Couleurs   | `theme/` — les jetons, le schéma sombre, un accent à vous      |
| Navigation | `docpensieve.config.mjs` — menu, en-tête, un menu dans la page |
| Alertes    | Vos pages — des blocs qui portent un avertissement             |
