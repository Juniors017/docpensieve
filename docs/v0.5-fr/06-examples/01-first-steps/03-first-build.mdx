Chaque page est un fichier complet, servi tel quel. Une page est un **dossier**
qui contient un `index.html`, ce qui lui donne une adresse terminée par une
barre oblique et ne demande aucune règle au serveur. La <Tooltip text="La seule feuille du site, compilée depuis les classes qu'emploient les pages.">feuille de style</Tooltip> suit ; aucun script ne suit.

## Quand quelque chose ne va pas

`build` s'arrête sur ce qu'il ne peut pas faire — un fichier manquant, un
composant mal employé — et le nomme. Il ne dit rien d'un lien qui vise une page
que vous avez renommée : cette page compilait parfaitement, elle n'est
simplement plus là.

```bash
npx docpensieve check
```

<Admonition type="tip" title="À lancer à chaque fois">
  `check` relit le site produit et sort en erreur si un lien ne mène nulle part. Cela coûte une
  seconde, et c'est la différence entre trouver un lien mort vous-même et le faire trouver par un
  lecteur.
</Admonition>

## Pendant que vous écrivez

```bash
npx docpensieve dev
```

Il sert le site et régénère à chaque enregistrement — y compris quand vous
changez la configuration ou un fichier du dossier `theme/`. Laissez-le tourner
dans un second terminal : la boucle entre écrire une phrase et la voir est ce
qui fait qu'une documentation s'écrit.
