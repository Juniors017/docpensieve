## A banner that follows the calendar

A notice can announce a release and remove itself once it is out:

<TimeTimer start="01/09/2026" duration="60d">
  <Card style={{ borderColor: 'var(--dp-accent)', background: 'var(--dp-accent-soft)' }}>
    <CardBody>**A new version is in preparation.** Try it on the beta channel.</CardBody>
  </Card>
  <FallbackAfter>The new version is out.</FallbackAfter>
</TimeTimer>

```mdx
<TimeTimer start="01/09/2026" duration="60d">

</TimeTimer>
```
