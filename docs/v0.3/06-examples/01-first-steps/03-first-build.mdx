# A first build

## Three commands

<Columns>
  <Column>
    <Card style={{ height: '100%' }}>
      <CardHeader>Build</CardHeader>
      <CardBody>`npx docpensieve build` writes the site into `dist/`.</CardBody>
    </Card>
  </Column>
  <Column>
    <Card style={{ height: '100%' }}>
      <CardHeader>Serve</CardHeader>
      <CardBody>`npx docpensieve dev` serves it, and rebuilds on every save.</CardBody>
    </Card>
  </Column>
  <Column>
    <Card style={{ height: '100%' }}>
      <CardHeader>Check</CardHeader>
      <CardBody>`npx docpensieve check` reads it back for dead links.</CardBody>
    </Card>
  </Column>
</Columns>

## What comes out

<Tree>
  <TreeItem label="dist" open>
    <TreeItem label="index.html — sends the reader to the current version" />
    <TreeItem label="versions" open>
      <TreeItem label="v1.0 — every page, as plain HTML" />
    </TreeItem>
  </TreeItem>
</Tree>

Each page is a complete file, served as it is. The <Tooltip text="The only stylesheet of the site, compiled from the classes the pages use.">stylesheet</Tooltip> comes along; no script does.
