## Before you start

You need <Tooltip text="The JavaScript runtime DocPensieve runs on — version 22 or later.">Node.js</Tooltip> and a terminal. Nothing else: the theme ships with the tool.

## Your turn

```bash
npx docpensieve init my-course
```

The command asks a few questions, then writes the project.
