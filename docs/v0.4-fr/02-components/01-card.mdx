# Card

## La plus simple

<Card style={{ maxWidth: '24rem' }}>
  <CardBody>Une carte réduite à son corps.</CardBody>
</Card>

```mdx
<Card>
  <CardBody>Une carte réduite à son corps.</CardBody>
</Card>
```

Les exemples de cette page rétrécissent certaines cartes par `style`, que tous
les thèmes comprennent ; l'apparence proprement dite vient plus bas.

## Avec ses trois parties

  </CardBody>

</Card>

## Avec une image

`CardImage` se place où vous voulez dans la carte. En haut ou en bas, elle suit
les angles ; entre deux blocs, elle reste carrée.

<Columns>
  <Column span={6}>
    <Card>
      <CardImage src="./icons/banner.svg" alt="" />
      <CardHeader>Image en haut</CardHeader>
      <CardBody>Les angles hauts suivent ceux de la carte.</CardBody>
    </Card>
  </Column>
  <Column span={6}>
    <Card>
      <CardHeader>Image en bas</CardHeader>
      <CardBody>Les angles bas suivent ceux de la carte.</CardBody>
      <CardImage src="./icons/banner.svg" alt="" />
    </Card>
  </Column>
</Columns>

```mdx
<Card>
  <CardImage src="./icons/banner.svg" alt="" />
  <CardBody>…</CardBody>
</Card>
```

`alt` vaut la chaîne vide par défaut : une image décorative est ainsi passée
sous silence par les lecteurs d'écran, plutôt qu'annoncée par son nom de
fichier. Une image porteuse de sens mérite un `alt` écrit.

## Entièrement cliquable

<Card style={{ maxWidth: '24rem' }} href="./columns/">
  <CardHeader>Aller aux colonnes</CardHeader>
  <CardBody>La carte entière est un lien, pas seulement le titre.</CardBody>
</Card>

```mdx
<Card href="./columns/">…</Card>
```

Une cible relative part de la page, une cible absolue de la racine de la
version — les mêmes règles que pour un lien Markdown.

## L'apparence par className

<ForTheme framework="tailwind">

Le composant n'offre aucune propriété de typographie : les utilitaires du thème
s'en chargent, et l'emportent sur le style par défaut.

<Card className="max-w-sm border-indigo-400 bg-indigo-50">
  <CardHeader className="text-center uppercase tracking-wide text-indigo-700">
    Centré, en capitales
  </CardHeader>
  <CardBody className="text-sm italic">Corps petit, en italique.</CardBody>
</Card>

```mdx
<Card className="border-indigo-400 bg-indigo-50">
  <CardHeader className="text-center uppercase tracking-wide text-indigo-700">
    Centré, en capitales
  </CardHeader>
  <CardBody className="text-sm italic">Corps petit, en italique.</CardBody>
</Card>
```

Les règles du composant vivent dans la couche `components`, sous les
utilitaires : un `className` posé à l'emploi l'emporte toujours, même pour
défaire le style par défaut.

<Card className="max-w-sm border-0 shadow-none bg-transparent">
  <CardBody className="px-0">Sans bordure, sans fond, sans marge intérieure.</CardBody>
</Card>

</ForTheme>
<ForTheme framework="custom">

Le composant n'offre aucune propriété de typographie : l'apparence vient de
classes à vous, écrites dans le dossier `theme/` — ici celles de
`theme/99-docpensieve.css`.

<Card className="narrow highlight">
  <CardHeader className="centered caps accent-text">Centré, en capitales</CardHeader>
  <CardBody className="small italic">Corps petit, en italique.</CardBody>
</Card>

```mdx
<Card className="highlight">
  <CardHeader className="centered caps accent-text">Centré, en capitales</CardHeader>
  <CardBody className="small italic">Corps petit, en italique.</CardBody>
</Card>
```

```css
.highlight {
  border-color: var(--dp-accent);
  background: var(--dp-accent-soft);
}

.caps {
  text-transform: uppercase;
  letter-spacing: 0.05em;
}
```

Les règles du composant vivent dans la couche `components`, celles du dossier
de thème dans aucune : une classe à vous l'emporte toujours, même pour défaire
le style par défaut.

<Card className="narrow plain">
  <CardBody className="flush">Sans bordure, sans fond, sans marge intérieure.</CardBody>
</Card>

</ForTheme>

La rangée la plus fréquente est une rangée de cartes ; [Columns](./columns/)
montre comment les tenir à la même hauteur, ce qu'une grille seule ne fait pas.
