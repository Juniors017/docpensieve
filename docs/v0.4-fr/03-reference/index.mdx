## Les erreurs

Toute erreur attendue porte un message et une **piste actionnable**. Une
configuration invalide, un slug de version inconnu, une valeur hors bornes :
chacune dit ce qui ne va pas et ce qui est attendu à la place.

Rien n'échoue en silence. Un composant qui ne peut pas rendre ce qu'on lui
demande arrête la génération plutôt que de produire un élément inerte — une
balise qui ne fait rien passe inaperçue à la relecture, une erreur non.

Pour les pannes qui ne disent rien — le site se génère et quelque chose ne va
pas quand même — le guide a [Quand ça casse](../guide/when-it-breaks/).
