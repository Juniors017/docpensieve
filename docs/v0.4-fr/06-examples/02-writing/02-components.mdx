## Un avertissement qu'on ne peut pas dépasser

Certaines phrases ne doivent pas se lire comme de la prose. Une admonition les
sort du texte :

<Admonition type="tip">
  Écrivez la leçon avant la référence. Un lecteur arrive avec une tâche, pas avec une liste
  d'options.
</Admonition>

<Admonition type="danger" title="Avant de supprimer une version">
  Son adresse cesse de répondre, et les liens qui la visaient ne mènent plus nulle part.
</Admonition>

### Les types que ce site a ajoutés

Six types sont livrés avec l'outil ; ces deux-là sont déclarés dans la
configuration de ce site même, avec une marque prise dans un jeu d'icônes :

<Admonition type="copilot">
  Un passage rédigé avec un assistant, puis relu et corrigé par une personne.
</Admonition>

<Admonition type="claude">
  Le même, et la page garde son auteur : la signature ci-dessus nomme une personne, pas un outil.
</Admonition>

```js
// docpensieve.config.mjs
admonitions: {
  claude: { label: 'Claude', tone: 'info', icon: 'simple-icons:claude' },
},
```

La marque est posée dans la page à la génération, comme toutes les autres
icônes ici : votre lecteur ne télécharge rien, et aucune requête ne part de son
navigateur.
